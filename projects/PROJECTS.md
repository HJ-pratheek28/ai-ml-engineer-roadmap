# Progressive Project Ladder

Projects are evidence of engineering ability. Each should have a clear problem statement, reproducible setup, tests, evaluation, limitations, and a concise technical write-up.

## 1. Programming foundations
- CLI file organizer or dataset cleaner.
- Python package with tests, type hints, logging, and a command-line interface.
- C++ implementation of core data structures with benchmarks.

## 2. Mathematics and algorithms
- NumPy linear/logistic regression from scratch.
- PCA with a visual explanation and numerical checks.
- Gradient descent visualizer and tiny automatic differentiation engine.

## 3. Data science
- End-to-end exploratory analysis with data validation.
- SQL analytics project with schema, indexes, and query-plan notes.
- Reproducible ETL pipeline with tests and data dictionary.

## 4. Classical ML
- Tabular classification/regression with baseline comparisons.
- Imbalanced classification with precision-recall analysis and threshold selection.
- Model error analysis and interpretability report.

## 5. Deep learning
- MLP and backpropagation from scratch.
- CNN image classifier with augmentation and ablations.
- Training pipeline with checkpoints, experiment tracking, and profiling.

## 6. NLP and LLMs
- Tokenizer and tiny GPT-style language model.
- Transformer implementation with shape tests.
- RAG system with retrieval evaluation, citations, and failure analysis.
- LLM tool workflow with robust validation, retries, and human approval.

## 7. AI systems
- CPU vs GPU benchmark with correctness tests.
- CUDA or Triton kernel with baseline comparison and profiler evidence.
- Quantized model serving benchmark: latency, throughput, memory, and quality.
- Distributed training experiment with scaling analysis.

## 8. Production
- Model API with authentication, tests, Docker, CI, monitoring, and rollback plan.
- Batch inference pipeline with data/model versioning and failure recovery.

## 9. Research
- Reproduce a paper's central result.
- Run ablations and report compute, seeds, variance, and deviations.
- Publish a technical report that separates reproduced results from new observations.

## 10. Capstones
1. **Production AI system:** a complete user-facing product with model evaluation, deployment, monitoring, and reliability practices.
2. **Research reproduction:** reproduce and extend a paper with transparent experiments.
3. **High-performance AI system:** optimize a training or inference workload and prove improvements with careful benchmarks.
4. **Independent AI product:** identify a real user problem, validate demand, build, deploy, and measure actual usage.

## Required project README
- Problem and intended users
- Architecture diagram
- Dataset/source and license
- Setup and reproduction instructions
- Baseline and evaluation methodology
- Results with metrics and benchmark environment
- Failure cases and limitations
- Next experiments
