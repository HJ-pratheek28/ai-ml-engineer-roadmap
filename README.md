# AI/ML Engineering Roadmap

A structured, free-first path from programming foundations to machine learning engineering, LLM systems, GPU computing, and research engineering.

**Primary target:** become an engineer who can understand the mathematics, implement models, build reliable AI products, and optimize the systems that serve them.

## Start here
1. Read [the complete roadmap](ROADMAP.md).
2. Follow the [24-month study plan](STUDY-PLAN.md).
3. Use [topic-by-topic resources](RESOURCES.md) as your learning library.
4. Build the projects in the roadmap. Do not treat watching lectures as completion.

## Learning principles
- Learn concepts, implement them, test them, and explain the trade-offs.
- Prefer official documentation and complete university courses.
- Keep a public engineering log: notes, experiments, benchmarks, failures, and conclusions.
- Use AI tools as assistants, not substitutes for independent reasoning.
- Revisit prerequisites whenever implementation exposes a gap.

## Completion standard
A topic is not complete because a course was watched. It is complete when you can:
1. Explain the central ideas without notes.
2. Implement a small version from scratch where appropriate.
3. Use a production-quality library correctly.
4. Evaluate results with meaningful metrics.
5. Identify limitations and communicate trade-offs.
